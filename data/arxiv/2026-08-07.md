# arXiv 论文追踪 - 2026.08.07

## 匹配论文：12 篇

### 1. ⭐×5 **SearchAuditor: Auditing and Attributing Failures in Long-Horizon Search Agents** (cs.AI)
- 作者：Zhixiang Liang, Yifei Liu, Yidan Huang 等
- 摘要：提出 SearchAuditBench 基准（1243 条失败轨迹）和 SearchAuditor 多视角审计框架，用于定位、归因和修复深度搜索 Agent 的长链推理失败。即使 GPT-5.5 基线端到端通过率仅 26.6%，SearchAuditor 达到 32.3%。
- 链接：https://arxiv.org/abs/2608.05212

### 2. ⭐×5 **Disentangling 3D Modeling from Spatial Reasoning (DiSR)** (cs.LG, cs.CV)
- 作者：Haoze Sun, Jiequan Cui, Qingshan Xu, Richang Hong
- 摘要：将 3D 感知与推理显式解耦：用专家模型重建几何结构，再用 LoRA 微调 LLM 仅在显式几何证据上推理。无需大规模 3D VQA 训练或复杂 tool-use 策略即可达到竞争性能。
- 链接：https://arxiv.org/abs/2608.05242

### 3. ⭐×4 **SkillTrace: Multi-Trace Provenance Auditing for LLM-Agent Skill Reuse** (cs.AI, cs.LG)
- 作者：Jialuo Chen, Minghe Wang, Lingqi Jiang 等
- 摘要：针对 LLM Agent 技能复用的多溯源审计框架，提取表达、实现、操作三条溯源迹线。在 820 个正样本和 751 个负样本上达 AUROC 0.938、F1 0.898。
- 链接：https://arxiv.org/abs/2608.05204

### 4. ⭐×4 **Woodpecker Distillation: Weak Models Diagnose Reasoning Bugs in Strong Models** (cs.AI, cs.CL)
- 作者：Dayu Wang, Jiaye Yang, Weikang Li 等
- 摘要：弱模型通过局部 patch 修复强模型的推理 bug。提出对比蒸馏框架，从成功/失败 patch 构建修正分布并蒸馏回强模型。数学推理基准上持续优于直接模仿基线。
- 链接：https://arxiv.org/abs/2608.05168

### 5. ⭐×5 **Safe Evolution with Circuit Anchors (CAE)** (cs.CL, cs.LG)
- 作者：Yan Liu, Jie Fu, Tsung-Yi Ho
- 摘要：受 Hox 基因启发，通过机械可解释性识别不到 2% 的安全回路并在进化中锚定。实现「可进化性+约束」：保持安全行为的同时允许能力自由进化。
- 链接：https://arxiv.org/abs/2608.05158

### 6. ⭐×4 **CRAFTER: Corrective Residual Agent with Feature-based Temporal Exploration and Reasoning** (cs.LG)
- 作者：Fangxin Wang, Ziyi Zhang, Diyi Zhuang 等
- 摘要：冻结预训练预测器，用组合搜索+LLM 发掘修正特征，通过验证门控自动筛选。在 6 个公开数据集上超越所有专用特征工程系统，最弱骨干误差降低最高 27%。
- 链接：https://arxiv.org/abs/2608.05207

### 7. ⭐×3 **Universal Pathologies: Triple-Robustness Analysis of RAG for Multi-Hop Traceability** (cs.CL, cs.AI)
- 作者：Meftun Akarsu, Burak Ozdemir
- 摘要：三轴鲁棒性分析：嵌入器、语料库、评判者。GraphRAG 引用精度 0.12-0.23，过度引用问题在不同语料上影响不同。提出三重鲁棒性作为 RAG 架构可信评估的最低门槛。
- 链接：https://arxiv.org/abs/2608.05153

### 8. ⭐×3 **Agentic Nesting: Multi-Agent Enterprise Application Integration** (cs.AI, cs.CL)
- 作者：Xi Wang, Kun Li, Xianyao Ling 等
- 摘要：提出「应用即 Agent」集成范式和「对话即集成」交互理念。将企业遗留应用封装为分层嵌套的自主 AI Agent，通过中央编排器协调任务分解和动态调度。
- 链接：https://arxiv.org/abs/2608.05159

### 9. ⭐×3 **Scaffold-Mediated Post-Training** (cs.CL)
- 作者：Fei Ding, Yongkang Zhang, Runhao Liu 等
- 摘要：程序化 scaffold 与模型参数共同进化的后训练范式。自动发现的 skill 提升通过率 8.1pp，渐进蒸馏后无外部 scaffold 仍达 27.7%（蒸馏保留率 85.2%）。
- 链接：https://arxiv.org/abs/2608.05156

### 10. ⭐×3 **SemiAdapt-Instruct: Modular Fine-Tuning via Latent Domain-Specialised Adapters** (cs.CL, cs.LG)
- 作者：Josh McGiff, Salma Mekaoui, Robert Shanahan 等
- 摘要：发现潜在指令域、并行训练每域 LoRA adapter、无参数路由。在所有配置上超越全模型微调，新增域只需单 adapter 训练。
- 链接：https://arxiv.org/abs/2608.05161

### 11. ⭐×3 **AuroSFT: Adapter-State Multi-Task Fine-Tuning** (cs.LG)
- 作者：Yue Han, Ziniu Liu
- 摘要：将多任务 SFT 的过拟合感知回滚状态转化为紧凑可合并的 adapter 状态。冻结骨干仅训练 adapter，平均准确率 61.36%，在全部 5 个骨干上超越 msft。
- 链接：https://arxiv.org/abs/2608.05250

### 12. ⭐×3 **AuroOFT: Expressive Quantized Orthogonal Fine-Tuning** (cs.LG)
- 作者：Yue Han, Ziniu Liu
- 摘要：在量化正交微调基础上附加零初始化门控低秩非线性残差。相比 QLoRA 节省 32.3-44.7% 可训练参数，在 Qwen2.5 1.5B/3B 上提升 1.30-2.70%。
- 链接：https://arxiv.org/abs/2608.05253
