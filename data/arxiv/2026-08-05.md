# arXiv 论文追踪 - 2026.08.05

## 匹配论文：8 篇

### 1. ⭐⭐⭐⭐⭐ **HyperAgent: Planning and Acting over Tool-Schema Hypergraphs for Tool-Use LLM Agents** (cs.AI)
- 关键词：LLM, agent, tool use, planning, reasoning
- 作者：Zian Zhai, Xingyu Tan, Gaowang Zou, Xiaoyang Wang, Wenjie Zhang
- 摘要：Large language model (LLM) agents increasingly rely on external tools to complete complex real-world tasks. We model tool relations at the schema level and construct a directed Tool-Schema Hypergraph. We propose HyperAgent, a Tool-Schema Hypergraph-guided framework for dynamic planning and execution. Experiments on AppWorld demonstrate that HyperAgent improves task completion performance while reducing redundant API calls, LLM interactions, and token consumption.
- 链接：https://arxiv.org/abs/2608.02650

### 2. ⭐⭐⭐⭐ **MemArena: An Ego-Centric Benchmark for On-Device Agentic Personal Memory Assistants at Scale** (cs.CL)
- 关键词：memory, agent, retrieval, RAG
- 作者：Jiadong Zhang, Xiaosong Ma
- 摘要：Edge-deployed personal memory assistants must handle private interpersonal conversations on-device with open-weight models. MemArena fills these gaps with a single-world conversational benchmark built with its MASim agent simulator, for 50 agents over 15 days (10.3M dialog-text tokens). We evaluate five open-weight readers with BM25-RAG, Oracle retrieval, Memobase, and MemSearch as memory backends.
- 链接：https://arxiv.org/abs/2608.02613

### 5. ⭐⭐ **BAP-SQL: Budget-Aware Observation Planning for Agentic Text-to-SQL** (cs.AI)
- 关键词：agent, tool use
- 作者：Zian Zhai, Xingyu Tan, Gaowang Zou 等
- 摘要：Tool-using agents do not merely consume observations: their actions determine what arrives next. In agentic text-to-SQL, a broad query can spend context and database work before useful evidence appears. We present BAP-SQL, which treats observation formation as a budget-control stage.
- 链接：https://arxiv.org/abs/2608.02876

### 6. ⭐⭐ **Knowing the Form, Not the Function: Automatically Auditing Answer-Authority Decoupling in Legal Benchmarks** (cs.CL)
- 关键词：reasoning, LLM
- 作者：Hsien-Jyh Liao
- 摘要：Under ordinary reasoning prompts, four LLMs spontaneously produced authority markers across 238 Taiwan bar-examination items. We automatically audit answer correctness and authority grounding jointly, finding the two dimensions dissociate in both directions.
- 链接：https://arxiv.org/abs/2608.02621

### 8. ⭐⭐ **BBOWP-Bench: Evaluating LLMs on Black-Box Optimization Word Problems** (cs.CL)
- 关键词：LLM, reasoning
- 作者：Yutaro Yamada, Kei Hiroshima, Nozomu Yoshinari 等
- 摘要：We introduce BBOWP, a novel problem setting in which a system must infer both a search space and an optimization algorithm from a natural-language description. We provide the first evaluation of LLMs and show that current LLMs are capable of selecting suitable algorithms, but sometimes struggle with search space design.
- 链接：https://arxiv.org/abs/2608.02612
