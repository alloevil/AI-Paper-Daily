- **检查模型**：`xiaomi/mimo-v2.5`（比 omni 更强）
- **发送方式**：飞书 API 上传图片

### 环境依赖
- Chromium: `/root/.cache/puppeteer/chrome/linux-149.0.7827.22/chrome-linux64/chrome`
- 依赖包: libnspr4, libnss3, libatk1.0-0, libatk-bridge2.0-0, libcups2, libdrm2, libxkbcommon0, libxcomposite1, libxdamage1, libxrandr2, libgbm1, libpango-1.0-0, libcairo2, libasound2, libatspi2.0-0, libxfixes3, libx11-xcb1, libxcb-dri3-0, libxss1, libxtst6, fonts-liberation
- WeasyPrint + 依赖: `/tmp/py-pkgs/`
- Puppeteer: `/tmp/node_modules/puppeteer`

### 教训
- PyMuPDF 不支持 emoji、阴影、圆角、flex 布局
- `insert_htmlbox` CSS 支持极有限（v2.5 打 3.5 分）
- 多模态检查应用 `mimo-v2.5` 而非 `mimo-v2-omni`
- 每次改动后必须先用 v2.5 检查再发给用户
