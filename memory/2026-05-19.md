### 最终架构

```
memory-core（内置 memory slot 主力）
├─ MEMORY.md + memory/*.md
├─ memory_search / memory_get
└─ SQLite 索引 + 向量搜索

agentmemory（MCP 补充层）
├─ iii-engine v0.11.2（localhost:3111，257 个函数）
├─ 87 个 session，318 条观察记录
├─ 33 条 session 摘要，16 条语义事实，8 条洞察
├─ MCP 代理已连通（standalone stdio 模式）
└─ LLM: xiaomi/mimo-v2.5 via mify
```

### 关键教训

1. **OpenClaw 保护机制**：`plugins.slots` 和 `plugins.entries` 是受保护配置路径，外部插件无法替换内置 memory-core
2. **iii-engine 启动顺序**：需要先启动 iii-engine 再启动 OpenClaw，否则 MCP 会 fallback 到 InMemoryKV
3. **agentmemory 定位**：会话记忆系统，不是知识库。适合捕获隐性知识，不适合结构化知识组织
4. **consolidation 流程**：observe → summarize → consolidate → decay，需要 LLM 配置（.env 中的 OPENAI_* 变量）
5. **数据分区**：手动导入的 facts 存在 KV.memories，consolidation 产出存在 KV.semantic
