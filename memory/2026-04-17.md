### 飞书文档操作经验
- `feishu_fetch_doc`（用户身份）有安全密级检查，未设密级的文档会报「未设置密级，禁止操作」
- `feishu_app_doc`（应用身份）可读取未设密级的文档，且 `update_blocks` 可直接修改 table cell 内的文本
- `update_blocks` 必须更新 cell 内的子文本 block（text block），不能直接更新 cell block，否则报「operation and block not match」
- `raw_content` GET API 用 tenant token 可读取完整 markdown，但 PUT 更新 API 返回 404（可能不支持 tenant token 写入）
- 应用身份绕过密级检查，适合批量读取/更新文档结构
