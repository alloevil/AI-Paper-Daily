## 卢总蒸馏经验（瑞林口述整理）

### 背景
用 OpenClaw 的 LLM Wiki 功能，将卢总相关文档进行结构化知识提取。

### 做法
1. **文档输入**：卢总相关文档
2. **知识提取**：使用 LLM Wiki 的 entity 提取能力，建立 ontology
3. **核心差异**：在标准 entity 之外，自建了**猜想、事实、决策**三类 entity
4. **应用方式**：提取完成后，让 Agent 结合 LLM Wiki 来使用这些结构化知识

### 反馈
- **卢总评价**：正面（"好的"）
- **现状**：有问题待解决，尚未到生产使用阶段

### 交付方式
- 提供了 skill 包给卢总
- 由卢总的助理来验证
- 卢总本人执行

### 要点
- LLM Wiki 不只是做"笔记整理"，而是做**知识蒸馏**——从非结构化文档中提取结构化的信念层
- 自定义 entity 类型（猜想/事实/决策）是关键创新点，让 wiki 从"信息存储"升级为"决策支持"
- 验证路径：skill 包 → 助理验证 → 本人执行（分层交付）
