### 容器权限探索（21:35-22:10）
- 发现容器升级后当前用户变成 node(uid=1000)，不再是 root
- sudo 被移除，su 需要密码
- 尝试开启 OpenClaw elevated 模式 → 飞书不支持 exec 审批（`feishu.capabilities = none`），审批超时
- elevated 开启后所有 exec 都被拦截（不只带 --elevated 的），需要关掉才能恢复普通命令
- 最终用 `apt-get download` + `dpkg-deb -x` 无 root 方式提取了 Chromium 系统依赖的 .so 文件到 `/tmp/chrome-libs/`
- headless Chrome 成功启动（CDP 端口 19825 可访问），但 bb-browser 的浏览器检测逻辑不识别 headless shell
- 结论：bb-browser 只适合本地 Mac 使用，服务器环境无法发挥核心价值
